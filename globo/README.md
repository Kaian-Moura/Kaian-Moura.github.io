# Apresentação Globo · Kaian Moura

- Arquivo principal: `globo.html`.
- `index.html` contém a mesma apresentação e permite abrir o diretório diretamente.
- Fotos e fonte locais em `imagens/`; licença da fonte incluída.

Ao editar a apresentação, mantenha `index.html` e `globo.html` sincronizados.
